# PhishGuard AI

نموذج تعليمي لتحليل مؤشرات التصيد والاحتيال في الرسائل بالذكاء الاصطناعي التوليدي.

## نشر التطبيق
1. ارفع `app.py` و`requirements.txt` إلى مستودع GitHub. لا ترفع مفاتيح API.
2. افتح https://share.streamlit.io/، وأنشئ تطبيقاً من المستودع، وحدد `app.py` كملف رئيسي.
3. في Advanced settings > Secrets، أضف السطر التالي مع مفتاحك الشخصي:

```toml
GROQ_API_KEY = "YOUR_NEW_PRIVATE_GROQ_API_KEY"
```

4. اضغط Deploy، وشارك الرابط الذي ينتهي بـ `.streamlit.app`.

**تحذير**: التطبيق نموذج تجريبي لا يتحقق من الروابط أو هوية المرسل فعلياً. لا تُدخل بيانات شخصية أو مالية حقيقية. استخدام API يخضع لحدود حساب Groq. إذا كان الرابط عاماً يمكن للزوار استهلاك حدود الاستخدام الخاصة بمفتاحك.
